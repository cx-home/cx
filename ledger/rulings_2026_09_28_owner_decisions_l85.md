## DOCS-50 — the bindings page is a fourth allowed page for a host language's name, as a binding's target only (L85 = (a))

DOCS-43 confines the word "Python" to the migration page, one comparison row and the quickstart's
host-language step, under `docs-voice-check`; the bindings section documents cxlib for Python beside
Go, Rust and V and cannot say what each binding binds without naming the language. Ruled: the
bindings page is a fourth allowed page, and on it a host language is named only as the target a
binding serves — one row per binding with its language, repository, status and a runnable example,
no comparative sentence — and the voice check's allowlist gains the page with that floor, in the
wave that re-voices it (DOCS-49's waves 5–7). Rejected: (b) bindings named by repository only — a
reader looking for the Python binding cannot find it; (c) dropping the guard for the reference
group — the erosion DOCS-43 closed.
