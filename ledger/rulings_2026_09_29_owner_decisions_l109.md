## HOSTL-1 — a page whose subject is a binding names its host language, as a fixed allowance the ratchet holds (L109 = (a))

The docs name a host language only on the three bridge pages (the migration page, the comparison's
one row, the quickstart's host-language step), and `docs-src/site/voice.cxd`'s `[python]` ratchet
holds every served source to its measured count, moving only down. The bindings section of the
guide, which documents the Python binding beside Go, Rust and V, reads the word 62 times, and the
Python binding's own repository page names itself. Ruled: a page whose SUBJECT is a binding — the
guide's bindings section and a binding's repository page — names its host language, in CX's voice
with its fixtures beside each claim; those pages' rows in `voice.cxd` become FIXED allowances at their
measured count, which the ratchet never lets rise, and every other page reads zero, so the rule keeps
exactly four named exceptions, all written in the ratchet file. Rejected: (b) zero everywhere, the
bindings page naming repositories and the ABI only — a reader looking for the Python binding would
find a page that avoids the word; (c) leaving the bindings row unruled at 62 — the voice pass would
end with an exception nobody took.
