    Performance

    Numbers and the bench setup that produced them.

    Parse

    Parse throughput on a single core at v0.7.0-dev — CX at roughly 380 MB/s, XML at 290 MB/s, JSON at 510 MB/s, YAML at 95 MB/s. Bench setup: M2 Pro, libcx built with -prod, 1 MB fixture per format.

    Emit

    Emit throughput follows parse — same order of magnitude per format. The canonical-form emitter pays an extra normalisation pass and runs around 60 percent of the regular emit.

    Eval

    The CXL streaming evaluator runs at 340 MB/s on the comparable bench corpus — about 17 percent under the comparable JSON benchmark on the same workload. Bench setup mirrors the parse row above: M2 Pro, libcx built with -prod, 1 MB fixture. The v0.7.0 target was 300 MB/s; that line has been crossed.

    Binding Overhead

    FFI overhead per call is in the low microseconds. Python ctypes adds about 35 microseconds per parse-and-emit round-trip on a 1 KB input; Go cgo is similar; Rust bindgen is closer to one microsecond. See the per-binding API pages for the exact wrappers.

    Methodology

    The bench is at vcx/tests/runners/streaming_bench.v and vcx/tests/runners/eval_features_bench.v. Run with make bench; results land in target/bench.json. The cross-binding parity check at scripts/run_bench_json.py compares per-binding times against the V baseline.
