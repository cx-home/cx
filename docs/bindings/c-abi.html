C ABI

Every libcx symbol that bindings link against. UTF-8 in, UTF-8 out, capability bits gate features.

Format Conversion

cchar *cx_to_cx        (const char *in, char **err);
char *cx_to_xml       (const char *in, char **err);
char *cx_to_json      (const char *in, char **err);
char *cx_to_yaml      (const char *in, char **err);
char *cx_to_toml      (const char *in, char **err);
char *cx_to_md        (const char *in, char **err);

Capability Bits

cx_features returns a 32-bit bitfield naming the capabilities the linked libcx supports. Each capability has a stable bit; bindings query before calling new symbols.

cunsigned int cx_features(void);

Threading and GC

libcx uses Boehm GC under the hood. Each calling thread must register before its first call and unregister at exit. Tier-1 bindings handle this automatically; embedders calling the C ABI directly should pair every thread setup with a tear-down.

cvoid cx_init(void);              // process-once initialization
void cx_thread_register(void);   // per-thread entry
void cx_thread_unregister(void); // per-thread exit

Memory

Every char-pointer returned by libcx is heap-allocated. Call cx_free to release it.

cvoid cx_free(void *p);

Header File

The dist/include/cx.h header is generated alongside the libcx build and ships with the release tarball. The header is the normative source of truth for the surface; this page tracks the same set in prose.
