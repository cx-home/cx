    Release Notes

    What shipped in v0.7.0 and v0.6.0, and how to migrate.

    v0.7.0 — Format-Stability Boundary

    v0.7.0 is the API and format-stability boundary through 1.0. C ABI symbols are append-only from here; ast-bin format versions are forward-compatible; the cross-binding conformance suite gates every release. The release ships the v0.7.0 evaluator, the parse-time and eval-time include resolvers, the Table API, and the documentation generator.

    v0.7.0: Added

    • CXL v0.7.0 — FLWOR for, multi-branch if, match, typeswitch, named templates, function values, partial application, error handling
    • Include resolver — parse-time and eval-time, shared containment + cycle detection
    • Table API with Tier-1 columnar surface
    • Doc generator (this site) and cx lsp subcommand
    • Streaming evaluator at 340 MB/s on the bench corpus — 17 percent under the comparable JSON benchmark

    v0.7.0: Changed

    • ADR 0017 collection literals — sequence, array, map
    • Bare prose with commas, em-dash, and equals parses as one Element body
    • Substituted attribute values in body position auto-quote when they would re-tokenize as structure
    • cx eval and cx --cx accept --include-root

    v0.7.0: Removed

    The W012 cx_eval_streaming stub is retired. Pre-G1 symbol names retired in favour of the renamed surface. See the migration section below.

    v0.6.0

    v0.6.0 introduced the collection-literal trio sequence array map per ADR 0017, the cross-binding API contract, the V-native data binding lane, and the schema validator at full Tier-1 coverage. The release also closed the bounded audit and brought every Tier-1 binding to parity on the C ABI surface.

    v0.6 → v0.7 Migration

    Six breaking changes ship with v0.7.0. Each is mechanical to update.

    M1: C ABI Symbol Rename

    Symbols matching cx_eval_cxl_* were renamed to cx_eval_* at G1. Bindings using the old names will fail to link. Replace cx_eval_cxl with cx_eval; cx_eval_cxl_with_target with cx_eval — the target is now the third positional argument.

    M2: Attribute Rename

    The columns attribute on :table renamed to cols. Existing tables that used columns parse as undeclared and warn under strict mode. The cx upgrade-config subcommand rewrites them automatically.

    shellcx upgrade-config orders.cx > orders.v07.cx

    M3: File Renames

    ADR 0021 renamed CXDB to cx:database. Library file lang/*/cxdb.* files renamed accordingly; build configs that name the file explicitly need an update.

    M4: Binding Cut

    Per the binding tiering decision, Tier-3 bindings Kotlin Swift Ruby TypeScript V-cffi are no longer feature-gating for v0.7.0. They lag by one minor release. Production users on a Tier-3 binding should expect a smaller feature surface until the per-binding catchup ships in v0.7.x.

    M5: W012 Stub Removed

    The cx_eval_streaming stub from v0.6.0 is removed. Use cx_eval with the streaming variant of the entry point. The C ABI symbol cx_eval_streaming returns NotImplemented if linked against; bindings that probed via cx_features bit 27 should detect support before calling.

    M6: ADR 0021 Rename

    CXDB is now cx:database internally. The user-facing CLI surface is unchanged (cx table is still cx table); internal references in ADRs and spec docs updated accordingly.
