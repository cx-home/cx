    Quickstart

    Five minutes from cx installed to your first parse, emit, and evaluator run.

    Setup

    This page assumes cx is on your PATH already; if not, the Install page covers each platform. The rest of Quickstart is a five-minute hands-on session.

    shellcx --version          # confirms the install
mkdir cx-tour && cd cx-tour

    Write a Document

    Save the following as menu.cx. Read it top to bottom — name, attributes, body items, nested children, mixed content. No commas required between attrs; no closing tag to repeat.

    cx[shop name='New Haven Pizza' open=true
  [hours mon-fri=11-22 sat=12-23 sun=closed]
  [menu
    [pizza #margherita size=large crust=thin  price=14.50]
    [pizza #pepperoni  size=large crust=thick price=16.00]
    [side  #salad      price=6.50]]]

    Parse

    shellcx --ast menu.cx       # JSON view of the parsed tree
cx --cx menu.cx        # canonical CX (attribute order normalised)

    The parse never returns a partial tree; a syntax error names the dialect, the byte offset, and the rule that failed.

    Emit to Another Format

    The same tree converts to any of the six dialects CX speaks. Try them.

    shellcx --json menu.cx
cx --xml  menu.cx
cx --yaml menu.cx
cx --toml menu.cx
cx --md   menu.cx

    Each command writes the result to stdout. Round-trip via the binary form (cx --cxdb | cx --from=cxdb) is byte-stable; round-trip via JSON / YAML / TOML / XML / Markdown is data-equivalent, with presentation-level differences documented on the comparison page.

    Evaluate a CXL Template

    CXL is CX that does things. Save the following as receipt.cxl alongside menu.cx.

    cx[?for p :in //pizza :return [line [?= p/@name] - [?= p/@price] euros;]]
    shellcx eval receipt.cxl --data=menu.cx

    The result is one receipt line per pizza in the menu. The directive language uses CXPath to query the data; the Tour of 50 Programs walks through the full directive vocabulary.

    Compute the Canonical Hash

    shellcx canonical menu.cx
cx hash menu.cx
cx eq menu.cx some-other-menu.cx

    The canonical form strips presentation comments attribute order anchor names whitespace and emits a data-equivalent byte-identical form. The hash is SHA-256 over those bytes. Two documents with the same data have the same hash — in any dialect, in any binding.

    Call CX From Your Language

    Every binding mirrors the CLI. Python by way of example:

    pythonimport cx
tree = cx.parse(open("menu.cx").read())
print(cx.emit(tree, to="json"))

    The Bindings pages cover Python, Go, Rust, V, TypeScript, Java, C-sharp, Ruby, Kotlin, and Swift — each idiomatic, all backed by the same libcx.
