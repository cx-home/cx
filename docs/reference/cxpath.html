CXPath Functions

Reference for the XPath 3.1 / 4.0 function library available in CXPath expressions.

String Functions

cxstring-length(s)        # codepoint count
substring(s, start, len)
contains(s, sub)        # bool
starts-with(s, prefix)
ends-with(s, suffix)
upper-case(s)
lower-case(s)
normalize-space(s)      # collapse whitespace
concat(a, b, …)
string-join(seq, sep)
replace(s, pat, rep)    # PCRE
matches(s, pat)         # PCRE bool
tokenize(s, sep)
encode-for-uri(s)

Node Functions

cxname(n)                 # qualified name with prefix
local-name(n)           # name without prefix
namespace-uri(n)
position()              # 1-based; current context
last()                  # size of the current sequence
count(seq)
exists(seq)
empty(seq)

Numeric Functions

cxnumber(x)              # cast to numeric
abs(x)
floor(x) / ceiling(x) / round(x)
sum(seq) / min(seq) / max(seq) / avg(seq)
format-number(x, picture)

Boolean and Logical

cxtrue() / false()
not(x)
boolean(x)             # effective boolean value

Sequence

cxhead(seq) / tail(seq)
reverse(seq)
distinct-values(seq)
remove(seq, position)
insert-before(seq, position, items)
subsequence(seq, start, len)

Date and Time

cxcurrent-date()
current-dateTime()
current-time()
year-from-date(d) / month-from-date(d) / day-from-date(d)
seconds-from-dateTime(dt) / minutes-from-dateTime(dt) / hours-from-dateTime(dt)

Higher-Order

cxfor-each(seq, fn)
filter(seq, predicate)
fold-left(seq, init, fn)
fold-right(seq, init, fn)
apply(fn, args)
function-arity(fn)

cx: Module

cxcx:parse(text)
cx:serialize(value)
cx:canonical(value)
cx:hash(value)
cx:merge(a, b)
cx:resolve-includes(value)

log: Module

cxlog:info(msg, fields?)
log:warn(msg, fields?)
log:error(msg, fields?)
log:debug(msg, fields?)
log:trace(msg, fields?)
log:with-context(fields, body)
