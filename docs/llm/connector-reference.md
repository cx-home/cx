# `cx-platform/connector`

The connector engine every connector feature runs on: the capability check at
the effect point, the open handle registry, the token cache, the spend ledger
and handle resolution.

A pure-CX package (RULED: RS-25) — no V code of its own. Source:
[`stdlib/connector.cx`](https://github.com/cx-home/cx-platform-connector/blob/main/stdlib/connector.cx).
Corpus:
[`conformance/platform/connector.cxd`](https://github.com/cx-home/cx-platform-connector/blob/main/conformance/platform/connector.cxd).
Spec:
[`spec/03-approved/platform/connector.md`](https://github.com/cx-home/cx-platform-connector/blob/main/spec/03-approved/platform/connector.md).
